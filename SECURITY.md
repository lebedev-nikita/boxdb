# Security policy

BoxDB is experimental version 0 software. There is no published long-term support
or security backport schedule. Use the latest release and test upgrades against
a copy of your data.

## Report a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/lebedev-nikita/boxdb/security/advisories/new)
for vulnerabilities affecting BoxDB. Include the affected version, platform,
minimal reproduction, impact and any proposed fix. Do not put exploit details,
credentials or private databases in public issues.

Regular bugs and usage questions belong in
[issues](https://github.com/lebedev-nikita/boxdb/issues/new/choose).
